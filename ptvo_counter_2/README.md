# ptvo_counter_2ch (Custom devices DiY) шаблон для SprutHub через Zigbee2MQTT

Шаблон устройства **ptvo_counter_2ch** для **SprutHub** при подключении через **Zigbee2MQTT (MQTT)**.

Шаблон позволяет добавить в SprutHub два импульсных счётчика, управляемое реле, а также базовую диагностику устройства (батарея, напряжение, качество связи).

## Возможности

Поддерживаются следующие параметры:

| Параметр | Тип | Единицы |
|----------|-----|---------|
| 🔢 Счётчик 1 (l3) | чтение / запись | импульсы (м³) |
| 🔢 Счётчик 2 (l5) | чтение / запись | импульсы (м³) |
| 🔌 Реле L6 | чтение / запись | Вкл / Выкл |
| 🔋 Уровень батареи | чтение | % |
| ⚡ Напряжение батареи | чтение | мВ |
| 📶 Качество связи (LQI) | чтение | значение |

---

## Требования

- SprutHub
- Zigbee2MQTT
- MQTT Broker
- ptvo_counter_2ch
- В Zigbee2MQTT должен быть включён режим публикации атрибутов по отдельным подтопикам (`advanced.output: "attribute"` или `"attribute_and_json"`) — без этого чтение параметров (`l3`, `l5`, `state_l6`, `battery`, `voltage`, `linkquality`) работать не будет.

---

## Установка

1. Скопируйте файл шаблона.
2. Импортируйте его в SprutHub:
   ```
   Настройки → Шаблоны устройств → MQTT → Импорт
   ```
3. Убедитесь, что имя устройства (friendly name) в Zigbee2MQTT соответствует модели `ptvo_counter_2ch`.
4. Запустите поиск в контроллере MQTT — устройство автоматически появится в SprutHub.

---

## Используемые MQTT-топики

Чтение (по отдельным атрибутам, требует `attribute`-режима вывода z2m):

```
zigbee2mqtt/<friendly_name>/l3
zigbee2mqtt/<friendly_name>/l5
zigbee2mqtt/<friendly_name>/state_l6
zigbee2mqtt/<friendly_name>/battery
zigbee2mqtt/<friendly_name>/voltage
zigbee2mqtt/<friendly_name>/linkquality
```

Запись команд (общий топик, JSON-пейлоад):

```
zigbee2mqtt/<friendly_name>/set
```

Пример пейлоада для включения реле:
```json
{"state_l6": "ON"}
```

Пример пейлоада для установки значения счётчика 1:
```json
{"l3": 123}
```

> ⚠️ В Zigbee2MQTT **нет** отдельных топиков вида `.../set/l3` или `.../set/state_l6` — команда всегда публикуется в общий топик `.../set` с JSON-объектом, где ключ соответствует нужному свойству. Шаблон формирует такой JSON автоматически через `outFunc`.

## Особенности

- Счётчики реализованы как накопительные измерители (`C_GasMeter` / `C_CubicMeter`), значение которых сохраняется между перезапусками хаба.
- Управление реле и запись значений счётчиков идёт через один общий топик `.../set` с автоматической сборкой JSON-пейлоада.
- Для батареи отображается предупреждение при уровне менее **20%**.
- Названия «Счётчик 1» / «Счётчик 2» — общие; при необходимости переименуйте их под фактическое назначение (вода, газ, электричество и т.д.).

---

## Известные ограничения

- Шаблон предназначен для подключения **через MQTT (Zigbee2MQTT)**, не через встроенный Zigbee-контроллер SprutHub.
- Корректная работа чтения зависит от настроек вывода Zigbee2MQTT (см. раздел «Требования»).
