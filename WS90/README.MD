# Shelly WS90 (EcoWitt) Template for SprutHub via Zigbee2MQTT

Шаблон устройства **Shelly WS90 (EcoWitt Weather Station)** для **SprutHub** при подключении через **Zigbee2MQTT (MQTT)**.

Шаблон позволяет добавить метеостанцию в SprutHub с отображением основных погодных параметров и дополнительных вычисляемых показателей, публикуемых Zigbee2MQTT.

## Возможности

Поддерживаются следующие параметры:

| Параметр | Единицы |
|----------|---------|
| 🌡 Температура | °C |
| 💧 Влажность | % |
| 🌬 Атмосферное давление | мм рт. ст. |
| ☀ Освещённость | lux |
| ☀️ УФ-индекс | UV Index |
| 🌡 Ощущаемая температура | °C |
| ❄ Ветроохлаждение | °C |
| 💦 Точка росы | °C |
| 🔥 Тепловой стресс | индекс |
| 🌪 Скорость ветра | м/с |
| 💨 Порывы ветра | м/с |
| 🧭 Направление ветра | ° |
| 🌧 Осадки | мм |
| 🌦 Интенсивность дождя | мм/ч |
| 💧 Датчик дождя | Да / Нет |
| ☁ Состояние погоды | текст |
| 🌡 Humidex | °C |
| 📈 Тренд давления | мм рт. ст. |
| 🔋 Уровень батареи | % |
| 📶 Качество связи (LQI) | значение |

---

## Требования

- SprutHub
- Zigbee2MQTT
- MQTT Broker
- Shelly WS90 (EcoWitt)

---

## Установка

1. Скопируйте файл шаблона.
2. Импортируйте его в SprutHub:
   ```
   Настройки → Шаблоны устройств → MQTT → Импорт
   ```
3. Убедитесь, что имя устройства в Zigbee2MQTT соответствует шаблону WS90.
4. Запустите поиск в контроллере MQTT устройство автоматически появится в SprutHub.

## Используемые MQTT-топики

Шаблон использует следующие значения Zigbee2MQTT:

```
temperature
humidity
pressure
illuminance
uv_index
dew_point
apparent_temperature
wind_chill
heat_stress
wind_speed
gust_speed
wind_direction
precipitation
rain_rate
rain_status
weather_condition
humidex
pressure_trend
battery
linkquality
```

## Особенности

- Давление автоматически переводится из hPa в **мм рт. ст.**
- Скорость и порывы ветра округляются до целого значения.
- Освещённость корректируется для совместимости с HomeKit.
- Статус погоды автоматически переводится на русский язык.
- Для батареи отображается предупреждение при уровне менее **20%**.

## Известные ограничения

Данный шаблон предназначен для подключения **через MQTT (Zigbee2MQTT)**.

При прямом подключении устройства к встроенному Zigbee-контроллеру SprutHub в некоторых версиях прошивки Shelly могут возникать проблемы с нестандартными manufacturer-specific кластерами (`FC01`, `FC02`, `FC03`).
